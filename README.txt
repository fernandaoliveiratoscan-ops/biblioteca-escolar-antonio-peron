BIBLIOTECA ESCOLAR ONLINE - VERSÃO COMPLETA
Escola Municipal Professor Antonio Peron

FUNCIONALIDADES
- Dashboard
- Cadastro e pesquisa de livros
- Cadastro e pesquisa de alunos
- Registro de empréstimos
- Registro de devoluções
- Controle automático da disponibilidade
- Identificação de atrasos
- Relatórios básicos

COMO TESTAR
1. Instale o Python 3.
2. Abra o terminal na pasta do projeto.
3. Execute: pip install -r requirements.txt
4. Execute: python app.py
5. Abra no navegador: http://127.0.0.1:5000
